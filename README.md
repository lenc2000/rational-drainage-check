# 소규모 유역 합리식 수리계산 웹앱

개발행위·농지·산지전용 등 소규모 유역의 **배수로 단면 통수 검토**를 웹에서 바로 하는 Streamlit 앱입니다.
엑셀 수리계산 양식으로 하던 과정을 그대로 옮겼습니다.

## 계산 흐름
| 단계 | 입력 | 계산 |
|---|---|---|
| ① 강우 조건 | 강우관측소(지역), 재현기간, 방재성능목표 1시간 값 | WAMIS 확률강우강도식 선택, 방재성능목표와 1시간 강우량 비교 |
| ② 유역·유량 | 유역면적 A, 유출계수 C(직접 또는 토지이용 가중평균), 유로연장 L, 표고차 H | 도달시간 → 강우강도 I → 첨두유량 Q = C·I·A/360 |
| ③ 단면 검토 | 사각(B×H) 또는 원형(D), 종단경사, 조도계수 | Manning 등류수심 → 수심비(기본 80% 이하), 유속(기본 0.8~3.0 m/s) 판정 |

결과는 화면에 바로 나오고, 계산 과정(계산서)과 CSV 내려받기를 제공합니다.

## 사용한 식
- 확률강우강도식 (WAMIS, General형): `I = a / (t^n + b)`  [I: mm/hr, t: 분]
- 도달시간
  - 유입시간: 직접 입력 또는 Kerby `t1 = 1.44 (L·N/√S)^0.467` [L: m]
  - 유하시간: Kraven(II) 경사별 유속표(S>1/100 → 3.5, 1/200~1/100 → 3.0, S<1/200 → 2.1 m/s),
    Rziha `V = 72 (H/L)^0.6 km/hr`, 또는 유속 직접 입력
  - Kirpich `tc = 3.976 L^0.77 S^-0.385` [L: km, 분] (전체 도달시간)
- 합리식 `Q = C·I·A / 360` [A: ha]
- 방재성능목표 보정(선택): `I' = I × (목표 1시간 강우량 / 강우강도식 1시간 강우량)` — 목표가 더 클 때만
- Manning `Q = (1/n)·A·R^(2/3)·S^(1/2)`, 원형관 최대통수 수심 0.938D

## 자료
- `data/idf_general_yeongnam.csv` : WAMIS 「전국 하천유역 홍수량 및 확률강우량 정보」(map.wamis.go.kr) 강우분석 →
  강우강도식_IDF_General형(GEV 분포, 지역빈도해석) 중 낙동강·형산강·태화강·회야강·동해·남해권과
  경북 인접 금강 상류 관측소 210곳, 재현기간 2~500년. 관측소명·좌표는 같은 페이지의 관측소 제원 자료.
- WAMIS 안내에 따르면 이 확률강우량은 **1시간 이상 자료**로 산정되었습니다. 도달시간이 1시간보다 짧은
  소규모 유역은 식을 연장해 쓰는 것이므로, 해당 설계기준과 발주청 협의에 따르십시오.

## 파일 구성
```
app.py                       화면 (입력·결과)
core/calc.py                 계산엔진 (강우강도식, 도달시간, 합리식, 단면 검토)
data/idf_general_yeongnam.csv  관측소별 강우강도식 계수
tests/test_calc.py           손계산 검산
```

## 내 컴퓨터에서 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 인터넷에 올리기 (Streamlit Community Cloud)
1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다 (`.streamlit` 폴더 포함).
2. https://share.streamlit.io 에 GitHub 계정으로 로그인 → **Create app** → 저장소 선택,
   Main file path 에 `app.py` 입력 → **Deploy**.
3. 몇 분 뒤 나오는 주소로 누구나 접속할 수 있습니다.
